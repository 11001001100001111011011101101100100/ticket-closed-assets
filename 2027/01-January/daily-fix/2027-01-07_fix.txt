FACEBOOK CAPTION:
One PC can't reach a site the others can? Check the hosts file for a leftover override.

Open PowerShell and run:
Get-Content "$env:SystemRoot\System32\drivers\etc\hosts"

Heads up: Lines starting with # are comments. Back up the file before you edit it as admin. Why it works: a hosts entry beats DNS, so one stale line can break one site. Ticket closed. (Resolution: hosts checked.)
