FACEBOOK CAPTION:
Merry Christmas. If this PC has joined the network before, Windows still has the key. List it, then show it.

Open Command Prompt as Administrator and run:
netsh wlan show profiles
netsh wlan show profile name="HomeWiFi" key=clear

Heads up: HomeWiFi is an example. The password shows in plain text. Use it on your own PC only. Why it works: Windows saves the key for every network the PC has joined. Ticket closed. (Resolution: password found.)
