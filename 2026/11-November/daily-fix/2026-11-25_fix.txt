FACEBOOK CAPTION:
Connected, no internet? Release the old address, ask for a new one, and flush the DNS cache.

Open Command Prompt as Administrator and run:
ipconfig /release
ipconfig /renew
ipconfig /flushdns

Heads up: This drops the connection for a few seconds. Don't run it over a remote session. Why it works: a stale address or cache is a common cause of no internet. Ticket closed. (Resolution: new IP.)
