FACEBOOK CAPTION:
Taskbar dead? Start menu stuck? Restart Explorer. Windows brings it back on its own.

Open PowerShell as Administrator and run:
# Windows relaunches it in a second
Stop-Process -Name explorer -Force

Heads up: Open File Explorer windows will close. Save anything in them first. Why it works: the desktop shell is just a process, and it can be restarted. Ticket closed. (Resolution: explorer restarted.)
